문서뷰어 — 사용법
====================

■ 실행 방법
  1) "문서뷰어.html" 파일을 더블클릭합니다.
     → 기본 웹브라우저(엣지/크롬 등)에서 뷰어가 열립니다.
  2) 별도 설치가 전혀 필요 없습니다. (인터넷도 필요 없음)

■ 문서 열기
  - 화면 왼쪽 "＋ 파일 열기" 버튼을 누르거나,
  - .docx / .xlsx 파일을 화면 위로 끌어다 놓으세요.
  - 여러 개를 한 번에 열 수 있고, 위쪽 탭으로 전환합니다.

■ 특징
  - 파일이 외부로 전송되지 않습니다. (내 PC 안에서만 열림)
  - 엑셀: 여러 시트, 셀 병합, 열 너비, 수식 결과값 표시
  - 워드: 서식 / 표 / 이미지 보존
  - 셀·글자 선택 후 Ctrl+C 로 복사 가능 (엑셀은 표 형태로 붙여넣기됨)

■ 배포 / 복사
  - 이 "문서뷰어.html" 파일 하나만 복사하면 어느 PC에서든 그대로 씁니다.
  - USB 로 옮겨도 되고, 사내 공유폴더에 두고 여럿이 써도 됩니다.

■ 참고
  - 읽기 전용 뷰어입니다. (문서를 수정/저장하는 기능은 없습니다.)
  - 엑셀 셀의 배경색/글꼴색 등 세부 서식은 표시되지 않습니다. (값·표 구조는 유지)
